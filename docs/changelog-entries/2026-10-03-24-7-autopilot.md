# 2026-10-03 — 24/7 Autopilot (overnight unattended replies)

## What changed

Lunabox can now keep handling a mailbox around the clock, even while the app is
closed — and, if you opt in, send **safe** replies on its own inside a window
you choose. Everything risky still becomes a draft.

- **Always processing.** The Gmail webhook now runs a bounded queue drain in the
  same invocation, so new mail is mirrored, triaged and drafted without the user
  opening the app (fixes the "enqueues but never drains" gap).
- **Watch health.** The daily cron reports lapsed/expiring watches and sync
  failures; `/activity` surfaces them.
- **Opt-in policy.** `/settings/autopilot` controls a mailbox policy: mode
  (`window` / `always`), timezone, days, hours, minimum confidence, known-sender
  requirement, category allowlist and per-hour/day/thread caps.
- **The gate.** `evaluateAutopilotGate` is a pure, ordered decision. Any
  ambiguity (`null` category or confidence), any guardrail violation, or any
  error resolves to **draft**, never send.
- **New guardrails.** `commitment_language` (prices, promises, legal terms) and
  `auto_responder` (no-reply addresses, out-of-office, mailing lists) force a
  draft.
- **Content-free audit.** Every evaluation writes an `autopilot_decisions` row:
  reason, category, confidence and boolean checks only — never message content.
- **Morning review.** The catch-up popup gains an "Overnight" block (sent /
  drafted / held with reasons); the inbox marks `handled overnight` rows.
- **Kill switch.** `AUTOPILOT_ENABLED=false` hard-disables every unattended send
  platform-wide with no deploy; `/settings/autopilot` pauses a single mailbox.
- **Agent tools.** `set_autopilot_policy`, `pause_autopilot`,
  `get_overnight_summary`, `explain_autopilot_decision`.
- **Ops.** Reconciliation for send/mirror drift, retention pruning, runbooks,
  and a `phase-autopilot` integration harness.

## Safety posture

No new OAuth scopes. Autopilot is off by default twice over (global flag allows
it; every mailbox policy starts disabled). Sends remain at-most-once via the
existing `send_ledger`.

## Migration

Additive only: two new tables (`autopilot_policies`, `autopilot_decisions`), new
`assistant_settings` columns, `mailboxes.sync_error`, `messages.auto_submitted`
and a drafts index. Old code ignores them, so a rolling deploy is safe.
